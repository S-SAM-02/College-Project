ABOUT OBJECT MIND

Intelligence with a clear point of view.

OBJECT MIND uses local MediaPipe hand landmarks for responsive pinch, fist and two-hand gestures. An open-vocabulary object detector recognizes a broad set of everyday objects, while a multi-person detector estimates the number of visible people. Camera frames are processed in the browser after the pretrained models are downloaded.

LOCALHand keypoints and gesture interpretation run on the current device; the hand mode does not upload its frames.
MODEL RUNTIMESObject Finder uses a text-prompt object detector with a common-object fallback; Person Finder uses COCO-SSD with an expanded detection limit. Runtime and pretrained weights are third-party; the app logic and UI are project-owned.
NLPExplicit rule-based commands and optional browser speech recognition.

Object Finder downloads Transformers.js and an open-vocabulary model; its fallback downloads TensorFlow.js, COCO-SSD, and the fallback weights. Person Finder downloads a pretrained COCO-SSD model, and hand tracking downloads MediaPipe models. First use requires internet access; object recognition can still miss small, distant or occluded items or produce false positives. Person counting estimates visible person boxes and does not identify individuals; overlapping people may be missed or double-counted.
