About Anime Reality

01 / OVERVIEW

About this website

ANIME REALITY is an AI-assisted gesture portal concept that combines live hand tracking with anime-inspired visual themes.

02 / INTERFACE

About this interface

The camera workspace detects a hand, displays gesture status, and draws a freeform portal when the two-hand thumb-and-index gesture is recognized. Choose a character to change the portal palette.

03 / TECHNOLOGY

Technologies used

DIP — visual input and image handling. NLP — typed anime and character name matching. ML / neural vision — MediaPipe hand-landmark detection and gesture logic. HTML, CSS and JavaScript — interface and interactions.

04 / LIVE SYSTEM

What is running

Browser camera stream, MediaPipe HandLandmarker, two-hand thumb-and-index gesture check, character-theme selector, fullscreen preview, and typed anime and character matching.

This prototype connects matching fingertips with straight lines and renders an original anime-inspired avatar in the gap. Camera resolution and frame rate depend on device/browser capability; 4K/60 FPS is not guaranteed.

05 / QUICK GUIDE

How to use

1. Choose a character. 2. Start the camera and allow permission. 3. Show both hands and extend the thumb and index finger on each hand to open the portal. 4. Type an anime title or character name in the Recognize anime box if needed. 5. Open the preview in fullscreen when needed.

06 / REQUIREMENTS

Browser & access

Camera access generally requires HTTPS or localhost. MediaPipe model files need an internet connection. Character recognition uses the text you type; no microphone is required.
