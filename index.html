ABOUT OBJECT MIND

Intelligence with a clear point of view.

OBJECT MIND uses the OpenAI vision API to analyze sampled camera frames for visible objects, approximate hand landmarks, and person counts. The preview stays in your browser, but sampled images are sent to your configured backend for processing.

DIPFrame sizing, coordinate mapping and temporal smoothing.
OPENAIVision analysis through a secure server endpoint; no third-party browser model files.
NLPExplicit rule-based commands, with optional browser speech recognition.

This project does not download TensorFlow, COCO-SSD, or MediaPipe model files. It sends compressed camera snapshots to OpenAI through the backend. Configure OPENAI_API_KEY in Vercel environment variables; API usage may incur charges. GPT-generated landmarks and counts are estimates, not guaranteed tracking measurements.
