About Anime Reality

01 / OVERVIEW

About this website

ANIME REALITY is an AI-assisted gesture portal concept that combines live hand tracking with anime-inspired visual themes.

02 / INTERFACE

About this interface

The camera workspace detects a hand, displays gesture status, and draws a themed square portal when the four-finger gesture is recognized. Choose a character to change the portal palette.

03 / TECHNOLOGY

Technologies used

DIP — visual input and image handling. NLP — voice-command interpretation. ML / neural vision — MediaPipe hand-landmark detection and gesture logic. HTML, CSS and JavaScript — interface and interactions.

04 / LIVE SYSTEM

What is running

Browser camera stream, MediaPipe HandLandmarker, four-finger gesture check, character-theme selector, fullscreen preview, and optional browser speech recognition.

This prototype currently renders a themed portal overlay; it does not yet replace the camera view with a fully generated anime world.

05 / QUICK GUIDE

How to use

1. Choose a character. 2. Start the camera and allow permission. 3. Hold one hand in view and show four fingers. 4. Or type an anime title or character name in the Recognize anime box and submit it. 5. Open the preview in fullscreen when needed.

06 / REQUIREMENTS

Browser & access

Camera access generally requires HTTPS or localhost. MediaPipe model files need an internet connection. Character recognition uses the text you type; no microphone is required.
