About Object Mind

Object Finder attempts to identify an item held near your hand. For uncommon or small items, enable Wide-vocabulary item scan and use good lighting. People Counter estimates the number of visible faces. Gesture Portal lets you draw virtual lines using thumb-and-index pinches. Models run in your browser and accuracy varies with item size, lighting, distance, and model vocabulary.

Controls: select a mode, start the camera, and use the voice toggle when spoken feedback is useful. In Gesture Portal, pinch thumb and index finger to draw; pinch with both hands twice to undo the last stroke.
